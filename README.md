# 🚀 Dev Stack

A modern and responsive web application that helps developers explore different technologies and build their ideal development stack.

Users can explore technologies by category, compare different options, and create a personalized technology stack by selecting the technologies they want to use.

## 🛠️ Technologies Used

- React.js
- Tailwind CSS
- TypeScript
- React-Toastify
- JSON — for technology data
- Vite — build tool

## ✨ Features

- Explore different development technologies
- Browse technologies by category
- Select technologies to build a custom stack
- View selected technologies in "Your Stack"
- Remove individual technologies
- Remove all selected technologies
- Toast notifications using React-Toastify
- Technology information with ratings and categories
- Responsive and modern user interface
- Technology data managed using JSON
- Clean and user-friendly design

## 📦 Dependencies
